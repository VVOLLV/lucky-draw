# 幸运抽奖 · Lucky Draw

单文件、零依赖的现场抽奖网页：分组揭晓 + 3D 翻牌动画 + 深浅双主题。

## 特性

- **分组抽奖**：默认按 5 → 3 → 1 → 1 依次揭晓，抽满自动结束
- **3D 翻牌**：中奖格从虚线空位翻出中奖名字，翻完掠过一道高光
- **深浅双主题**：右上角一键切换；浅色对齐 TraeWork Light 规范（白底 + 靛紫品牌色），偏好自动持久化，刷新不闪烁
- **参与名单侧栏**：可开关、可全屏展开，实时显示人数统计，已中奖者高亮
- **不重复中奖**：名单去重，每人最多中一次
- **单文件零依赖**：不联网也能跑，双击即用

## 使用

直接双击打开 `index.html`。或在目录下起一个本地服务：

```bash
python3 -m http.server 8123
```

然后访问 <http://localhost:8123>。

## 操作

点「开始抽奖」→ 名字滚动 → 再点「停！」→ 本组中奖者一起亮出。抽完一组按钮变为「抽下一组」，「重置」清空重来。右上角 ☀/☾ 按钮切换深色/浅色主题。

## 自定义

改 `index.html` 底部的几个常量即可：

| 位置 | 说明 |
| --- | --- |
| `PARTICIPANTS` | 候选人名单，一行一个名字 |
| `GROUPS` | 分组与人数，`{ label, count }`，数组顺序即抽取顺序 |
| `ROLL_INTERVAL` | 滚动速度（毫秒，越小越快） |
| `:root` | 设计 token：配色、圆角、字号，改一处全局生效 |

总人数由 `GROUPS` 自动汇总，无需手改。
